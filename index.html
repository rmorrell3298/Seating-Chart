Privacy-first prototype Student roster and seating data are saved only in this browser on this device using local storage. This prototype does not send roster data to a server or require an account. Exported backups are created locally on your device. If browser data is cleared, the saved information may be erased. On a shared Chromebook, sign out when finished and avoid using a shared browser profile.
